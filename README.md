# CoCo: a contrastive loss that regresses the batch Gram matrix onto a simplex ETF

Code, experiments and statistical analysis for the paper


> **Collapsed and Contrasted Loss for Learning Optimally Separated Class Representations**
> Blanca Cano-Camarero, Ángela Fernández Pascual and José R. Dorronsoro — Departamento de ingeniería informática UAM 
> Submitted to ESANN 2027 (European Symposium on Artificial Neural Networks,
> Computational Intelligence and Machine Learning).

CoCo is a supervised contrastive loss that needs no temperature, no projection head and
no normalisation. It compares the embeddings of two independently shuffled batches and
regresses their inner products onto the Gram matrix of a simplex equiangular tight frame
(ETF), while keeping the embedding norms close to one. The network output is itself the
embedding, and a sample is classified by the nearest training class mean.

## The CoCo loss

For two independently shuffled batches $(z_i, y_i)_{i=1}^{B}$ and for raw (un-normalised) network outputs:
$(z’_j, y’_j)_{j=1}^{B}$

The CoCo loss is defined as:

$$
\mathcal{L}{\text{CoCo}} =
\frac{1}{B^2}
\sum{i,j}
\left(
\langle z_i, z’_j \rangle - g(y_i, y’_j)
\right)^2
+
\frac{1}{B}
\sum_i
\left(
\lVert z_i \rVert^2 - 1
\right)^2
+
\frac{1}{B}
\sum_j
\left(
\lVert z’_j \rVert^2 - 1
\right)^2
$$

where

$$
g(a,b) =
\begin{cases}
1 & \text{if } a=b, \\
-\frac{1}{C-1} & \text{if } a\neq b.
\end{cases}
$$

At the optimum the class embeddings form a simplex ETF, and the prediction rule
$\hat y(x) = \arg\max_k \langle h(x), s_k\rangle$, with $s_k$ the mean training
embedding of class $k$, recovers the label.

```python
import torch
from torch.utils.data import DataLoader
from cocobench.losses import CoCoLoss

criterion = CoCoLoss(num_classes=C)                 # normalize=False by default
loader1 = DataLoader(train_ds, batch_size=32, shuffle=True, drop_last=True)
loader2 = DataLoader(train_ds, batch_size=32, shuffle=True, drop_last=True)

for (x1, y1), (x2, y2) in zip(loader1, loader2):
    loss = criterion(model(x1), model(x2), y1, y2)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

A complete runnable example (training, class-mean prediction and the learned Gram matrix)
is in [`examples/minimal_coco.py`](examples/minimal_coco.py).

```

  model.py         MLP shared by all losses
  data.py          OpenML / sklearn / CSV loading and preprocessing
  train.py         training loop (double loader for CoCo), early stopping, prediction rules, metrics
  nested_cv.py     nested cross-validation with hyperparameter grid search

  analyze_results.py   statistical analysis reported in the paper
examples/
  minimal_coco.py      minimal CoCo training example
results/           per-dataset results of the paper's experiments + analysis/ outputs
tests/             unit and end-to-end tests
```

## Reproducing the experiments

```bash
python run_dataset.py --sklearn iris --quick   # smoke test, no internet needed
./run_one.sh 31                                 # one OpenML task (credit-g)
./run_all.sh -j 6                               # all 72 CC18 tasks, 6 in parallel, then the analysis
```

Each dataset runs in its own process and an interrupted run resumes at the first missing
(method, outer fold). Work can be split across machines with `--folds 0 1 2 …`.
CPU is the default device: the networks are small and the batch size is 32, so GPU
kernel-launch overhead dominates. For throughput, run many datasets in parallel.

## Reproducing the analysis

The `results/` folder contains, for each dataset, everything the analysis needs
(`outer_metrics.csv`, `best_params.csv`, `dataset_info.json`, `config.json`,
`summary.csv`, `histories/`). Per-sample predictions and inner-CV logs are not included
because of their size; they are regenerated by the scripts above.

```bash
python analysis/analyze_results.py --results results --out results/analysis
```

This writes `report.md` (full report), `results_table.tex` (paper table) and the CSV
files `per_dataset_means.csv`, `per_dataset_wtl.csv`, `across_dataset_tests.csv`,
`imbalance.csv` and `training_dynamics.csv`.

## Experimental protocol

| Item | Setting |
|---|---|
| Data | OpenML-CC18 (72 datasets). One target (fewest classes if several). Rows with missing values removed, constant columns removed, classes with < 10 samples removed. Numeric → z-score, categorical → one-hot, fitted on each training split only. Four datasets that appear under two task ids are counted once (lowest task id). |
| Network | d → N1 → ReLU → N2 → ReLU → C, with N1 = min(512, max(4d, 10)), N2 = (N1 + C) // 2; L2-normalised output for SupCon, Dot-Regression and CoCo with normalisation. |
| Losses | Cross-entropy; SupCon (τ = 0.07); CoCo with two independent shuffled loaders; Dot-Regression with a fixed simplex ETF. |
| Prediction | CE: argmax of logits · DR: argmax ⟨h, w_c⟩ · CoCo: argmax ⟨h, s_k⟩ with s_k the training class means · SupCon: cosine similarity to the training class means. |
| Optimisation | AdamW, batch 32 (drop_last), at most 100 epochs, early stopping (patience 5) on the balanced accuracy of a stratified 10 % hold-out of the training split, best weights restored. |
| Grid | lr ∈ {1e-4, 3e-4, 1e-3, 3e-3} × weight decay ∈ {0, 1e-4, 1e-3, 1e-2}; CoCo additionally normalisation ∈ {no, yes}. |
| Cross-validation | Outer stratified 10-fold; inner stratified 5-fold on the outer-training part; selection by mean inner balanced accuracy; refit on the full outer-training part. |
| Metrics | Balanced accuracy, macro F1, Cohen's κ, macro precision (plus accuracy, MCC, weighted scores and ROC-AUC in the raw outputs). |
| Statistics | Friedman test over the per-dataset means followed by paired Wilcoxon tests CoCo vs each baseline with Holm correction (Demšar, 2006); per-dataset Wilcoxon-Holm win/tie/loss counts over the outer folds; exploratory analyses of class imbalance and training dynamics. |
